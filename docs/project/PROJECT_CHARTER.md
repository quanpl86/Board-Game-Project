# Project Charter — Board Game Universe
**Status:** Proposed · **Version:** 1.0 · **Date:** 2026-10-09

## Vision
A scalable, AI-native web-based multi-game ecosystem with board, card, strategy, STEM, 3D simulation and coding games. One identity, multi-tenant platform, game SDK, LiveOps and MCP control plane.

## Users
- Public players: bots, friend invites, local and private online multiplayer, competitions.
- Students 7–15: learning tasks, safe group interaction, achievements and STEM challenges.
- Teachers / schools: classroom, groups, assignment, rubric and assessment dashboards.
- Clubs / organizers: team registrations, tournament, officials, dispute workflows and rankings.
- Editors / game authors: publish game versions, content, asset and seasonal campaigns.
- Agents: delegated, audited, policy-governed content creation and operational workflows.

## Pillars
1. Game-agnostic plugin integration and authoritative game rules.
2. Multi-tenant identity, roles and attribute-based access control.
3. Safe communication, classroom and event workflows.
4. CMS, dynamic content and seasonal campaign automation.
5. Learning analytics and secure sandboxed Coding Arena.
6. MCP tools, Agent Registry and approval-based automation.
7. Source-controlled design, QA, metrics and operations.

## Exclusions from initial MVP
Unmoderated minor-to-stranger DMs; open execution of user-supplied server code; full microservice decomposition; licensed modern game adaptations without rights; automated final academic evaluation without teacher oversight.

## Validation milestones
First end-to-end 2D classic game + Eco City Lab 3D share identity, catalog, session, scoring and CMS; classroom pilot with safe messaging; one approved MCP campaign workflow; load/restore/security testing before production.
