# Iconography Vocabulary
**UI source:** one approved Lucide version, consistent outlined style; graphics inside game worlds can differ.

| Action | Icon semantic name | UI location | Label |
|---|---|---|---|

| Create room | `plus` | Game detail | Tạo phòng |
| Save | `save` | Settings/wardrobe | Lưu thay đổi |
| Inventory | `backpack` / `package` | Player Hub | Tủ đồ |
| Shop | `shopping-bag` | Hub nav | Cửa hàng |

| Group | `users` | Team/Classroom | Đội nhóm |

| Undo / restart | `undo-2` / `rotate-ccw` | Game HUD | Hoàn tác / Chơi lại |

**Sizes:** 16–18px compact text icon, 20px standard button, 24px section/action, 32px card hero; icon containers 40–56px. Stroke consistent 1.75–2; button hit target >=44px. Icons use `currentColor` and global semantic color, not arbitrary palette. Use aria-hidden for decorative, aria-label for icon-only. Stop if symbol's meaning is ambiguous across cultures.
